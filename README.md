# SeuLab · Editor de Vídeos IA

Primeira edição da linha de produtos SeuLab, desenvolvida pela Pulso Lab. O kit ensina quem não sabe programar a editar e criar vídeos com o Claude Code ou o Codex, usando o [Remotion](https://github.com/remotion-dev/remotion) (versão 4.0.535).

## O que tem aqui

| Pasta | Arquivo | O que é |
|---|---|---|
| `paginas/` | `vendas.html` | Página de vendas do SeuLab (R$ 97, garantia de 7 dias) |
| `paginas/` | `area-do-aluno.html` | Área do produto: instalação visual e os dois caminhos (editar um vídeo ou criar uma animação) |
| `paginas/` | `guia-v1-remotion-skills.html` | Primeira versão do guia, com 12 receitas, mantida como referência |
| `roteiros/` | `Roteiros-Anuncio-SeuLab.pdf` | Roteiros dos anúncios: principal, versão de 15s e 3 variações |
| `roteiros/` | `roteiros.html` | Fonte do PDF dos roteiros |
| `prompts/` | `prompt-gerador-de-guias.md` | O prompt que transforma um repositório em guia, para as próximas edições |

## Identidade visual

A marca, paleta, tipografia, componentes e regras de comunicação estão documentados em `IDENTIDADE-VISUAL.md`. Os arquivos vetoriais da marca ficam em `assets/`.

## Como ver as páginas

Baixe o arquivo `.html` e abra no navegador com dois cliques.

## Antes de vender

- [ ] Testar o caminho A (editar um vídeo) e o caminho B (vídeo animado) de ponta a ponta
- [ ] Testar a etapa A0 (roteiros) e o prompt de instalação no Windows e no Mac
- [ ] Conferir os nomes dos botões dos apps do Claude e do Codex nas ilustrações
- [ ] Conectar o link do checkout no botão de compra da página de vendas
- [ ] Definir o preço final
- [ ] Liberar a área do aluno só para quem comprou

## Aviso

Guia independente, sem afiliação com o Remotion, a Anthropic ou a OpenAI. O Remotion é gratuito para pessoas físicas e empresas com até 3 funcionários; empresas maiores precisam de licença ([remotion.dev/license](https://remotion.dev/license)).
