Caminho fácil

Um prompt que instala, configura e testa

Crie uma pasta vazia chamada meus-videos, abra o Claude Code ou o Codex dentro dela e cole:

Quero usar o Remotion Agent Skills para criar vídeos. Eu não sei programar, então me guie em português, um passo de cada vez, e explique o que está acontecendo.

1. Verifique se o Node.js e o Git estão instalados. Se faltar algum, me diga exatamente como instalar no meu sistema e espere eu confirmar.
2. Instale as habilidades com o comando: npx skills add remotion-dev/skills
3. Crie um projeto de vídeo de teste nesta pasta.
4. Faça um vídeo de 5 segundos com o texto "Meu primeiro vídeo" em letras grandes.
5. Abra o Remotion Studio para eu ver a prévia no navegador.
6. No final, me diga o que deu certo e qual é o próximo passo.

Na tela: a IA vai pedir permissão antes de rodar cada comando. Leia e aprove. Na primeira vez, a instalação leva alguns minutos.

Caminho manual

Passo a passo, com o que aparece na tela

  1. Instale o Node.js

    Entre em nodejs.org, baixe a versão marcada como LTS e instale como qualquer programa. O Node.js é o que faz os comandos de vídeo funcionarem.

  2. Instale o Git

    Entre em git-scm.com e instale. No Mac, ele costuma já vir instalado.

  3. Abra o Claude Code ou o Codex numa pasta nova

    Crie uma pasta chamada meus-videos e abra a ferramenta de IA dentro dela.

  4. Instale as habilidades de vídeo

    Peça para a IA rodar o comando abaixo, ou cole no terminal:

    npx skills add remotion-dev/skills

    Na tela: uma lista das habilidades instaladas, como remotion-create, remotion-render e remotion-captions.

  5. Reinicie a conversa

    Feche e abra o Claude Code ou o Codex de novo para que ele carregue as habilidades novas.

00:09 · Ficha de transparência

O que você precisa saber antes de começar

Quanto custa

  • As habilidades do Remotion são gratuitas e de código aberto.
  • O Remotion é gratuito para pessoas físicas e empresas com até 3 funcionários. Empresas maiores precisam de licença paga. Confira em remotion.dev/license.
  • O Claude Code e o Codex exigem um plano pago da Anthropic ou da OpenAI.
  • A locução com IA usa o ElevenLabs, que tem plano gratuito limitado e planos pagos.

O que você precisa ter

  • Computador Mac, Windows ou Linux.
  • Node.js e Git instalados (gratuitos).
  • Para legendas automáticas a partir do áudio: placa de vídeo compatível. Sem ela, use um arquivo de legenda .srt.
  • Para mapas: o estilo MapLibre é gratuito e não pede chave. Mapbox pede uma chave própria.

Limitações

  • Não é um editor de arrastar e soltar como o CapCut. Você pede, a IA escreve o vídeo e você ajusta na prévia.
  • Exportar vídeos longos usa bastante o computador e pode demorar.
  • O resultado depende da clareza do pedido. Pedidos vagos geram vídeos genéricos.

O que o kit não faz

  • Não grava vídeo nem tira fotos.
  • Não publica nas redes sociais.
  • Não cria imagens de pessoas ou produtos do zero. Use as suas fotos e vídeos.

Fonte e versão

00:10 · Dúvidas e problemas comuns

Se algo der errado

Apareceu "npx não é reconhecido" ou "command not found".

O Node.js não está instalado ou o computador ainda não o reconheceu. Instale pelo nodejs.org, feche e abra o Claude Code ou o Codex de novo e tente outra vez.

A prévia não abriu no navegador.

Peça "/remotion-studio abra a prévia". A IA vai mostrar um endereço que começa com http://localhost. Copie esse endereço e cole no seu navegador.

A transcrição para legendas deu erro.

A transcrição automática roda no seu computador e precisa de uma placa de vídeo compatível. Se não funcionar, gere a legenda em outro serviço, salve como arquivo .srt e peça: "importe as legendas do arquivo legenda.srt".

O vídeo saiu com textos em inglês ou com cara de modelo pronto.

Diga sempre "em português do Brasil" e descreva o estilo: cores, fontes, tom e para quem é o vídeo. Quanto mais específico o pedido, mais o resultado parece seu.

Fiz uma mudança na prévia e a IA desfez.

As habilidades orientam a IA a preservar as suas mudanças. Se acontecer, avise: "eu mudei o título manualmente, mantenha a minha versão".

Como atualizo as habilidades?

Peça "/remotion-upgrade". A IA atualiza o Remotion e as habilidades instaladas.

Onde fica o meu vídeo final?

Na pasta "out", dentro do seu projeto. Peça "me diga onde o arquivo ficou" que a IA mostra o caminho.

00:11 · Mini glossário

As palavras que aparecem no caminho

Habilidade (skill)
Um manual que ensina a IA a fazer uma tarefa específica do jeito certo.
Remotion
A tecnologia que transforma código em vídeo. A IA escreve o código, você só conversa.
Remotion Studio
A tela no navegador onde você assiste à prévia e vê a linha do tempo.
Terminal
A janela de texto onde os comandos rodam. A IA usa por você.
Node.js
Programa gratuito que faz os comandos do Remotion funcionarem.
npx
O começo dos comandos de instalação. Vem junto com o Node.js.
Composição
Um vídeo dentro do projeto, com tamanho e duração próprios.
Renderizar
Transformar a prévia em um arquivo de vídeo de verdade, como MP4.
FPS
Quadros por segundo. 30 FPS é o padrão das redes sociais.
Chave de API
Uma senha que liga um serviço, como o ElevenLabs, ao seu projeto. Não compartilhe.
.srt
Arquivo de legenda com o texto e o tempo de cada frase.
Light leak
Efeito de vazamento de luz, comum em vídeos com cara de cinema.
